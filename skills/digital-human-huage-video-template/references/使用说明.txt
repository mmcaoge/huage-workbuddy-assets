三、片头 / 片尾模板
-------------------
每个类别文件夹下已生成：
- 片头.mp4   (约 5 秒)
- 片尾.mp4   (约 5 秒)

视觉沿用「新时代的中国人」红底金字风格。
片头：新时代的中国人 + 华哥·解读·类别 + 主办/协办/出品/总编辑 + 口号。
片尾：五大品牌 + 软钩子 + 口号。

四、出片流程（以 03_政策红利库 双十五税为例）
------------------------------------------------
1. 写文案并拆成 5 句，每句给定时长。
2. 生成该类别的配音（VideoGen 原生 / edge-tts / 真人录音）。
3. 修改技能工具/gen_category_video.py 里的 CFG：
   - folder：类别文件夹名
   - voice：配音文件路径
   - lines：文案列表 + 每句时长
   - out_name：成片文件名
4. 运行脚本：
   python gen_category_video.py
5. 脚本自动：数字人循环铺满 → 烧字幕 → 混 BGM → 拼片头片尾。

注意：
- VideoGen 单条数字人只有 5 秒，脚本会自动循环。循环后嘴型会重复，属工具限制。
- VideoGen 输出右下角自带「视频由AI生成」水印，参考视频也有。
- 片头片尾如需改动，改 gen_intro_outro_v3.py 后重新生成。
