# 数字人视频品牌片头片尾规范 v1
（零成本开源合成 · 全平台发布 · 正片纯净）

## 0. 适用范围与铁律
- **合成方式**：服务器开源管线（Wav2Lip 对口型 + ffmpeg 字幕/包装），**零新增支出**，不用万相/可灵/火山等按秒计费平台。
- **画幅**：9:16 竖屏（1080×1920），适配视频号 / 朋友圈 / 抖音 / 小红书 / 服务号 / 闲鱼等所有平台。
- **正片（口播主体）全程纯净**：无角标、无水印、无品牌条、无贴片广告；字幕只在底部安全区，不遮挡人脸。
- **品牌只出现在两处**：片头立 IP、片尾收口。
- **合规红线**：钩子只用「微信搜一搜 + 品牌词」，**绝不露个人微信号 18889153888**（百家号前车之鉴）。

## 1. 片头（约 6 秒，4 帧，建立 IP 与人格）
- **帧1（0–1.5s）品牌资产动画**：蓝紫钻石 + 12 黄星 + 粉紫圆弧 + 口号「传递民意·践行价值」一闪而过。
- **帧2（1.5–3s）主 IP + 栏目**：亮「**新时代的中国人**」母品牌，下面挂栏目「**华哥·解读**」。层级关系一次讲清——新时代的中国人（整体数字内容 IP，涵盖榜上有鸣短剧/政策解读）为伞，华哥·解读（政策/商业情报栏目）为下挂栏目。
- **帧3（3–4.5s）身份卡**：「国庆 · 总经办主任 · 海南铎鸣社会调查网」+「鸣儿·商业情报助手 出品」，人与产品同框。
- **帧4（4.5–6s）本期主题**：如「双15%怎么省」→ 转场入正片。

## 2. 正片（口播主体，纯净无叠加）
- **底图**：`c0efb50f`（办公室 + 三旗照）。**禁用** `0416` 第一张。脸占整图偏小 + 真实环境参照，对口型最不假。
- **画面效果**：嘴随口播动（Wav2Lip，仅嘴部区域）+ 镜头轻微推拉平移（Ken Burns）+ 底部时间轴字幕。
- **正片上面什么品牌元素都不放**（含角标/水印/水印条一律不加）。
- 字幕：底部安全区，白字描边，不挡脸。

## 3. 片尾（固定 3–5 秒，品牌收口）
单张「品牌收口卡」停留 **3–5 秒**（所有视频统一时长，不浮动）：
- **五品牌并列**（一行或两行排版，字号统一）：
  海南社会调查网 / 海南铎鸣社会调查网 / 鸣儿·商业情报助手 / 榜上有鸣 / 新时代的中国人
- **软钩子（居中）**：微信搜一搜：鸣儿·商业情报助手
- **口号（底部）**：传递民意·践行价值
- **配色**：蓝紫钻石主色 + 粉紫圆弧，与片头视觉一致，形成品牌记忆。

## 4. 全平台发布适配
- 同一成片 9:16，视频号 / 抖音 / 小红书 / 服务号 / 朋友圈 / 闲鱼 **通用**，无需二次剪辑。
- **钩子文本按生态微调**（仅改这一句，五品牌与口号固定不动）：
  - 微信生态（视频号/服务号/朋友圈）：「微信搜一搜：鸣儿·商业情报助手」
  - 其他平台（抖音/小红书/闲鱼）：「搜 鸣儿商业情报助手」
- **封面图**：取片头帧2 或 正片首帧，叠加本期标题文字（如「双15%怎么省」）。

## 5. 合成参数（供后续脚本复用，仍是零成本）
- **片头**：6s 固定素材，预渲染一次、每条复用。
- **正片**：Wav2Lip 输出静帧序列 + ffmpeg `zoompan` 轻微推拉 + `drawtext` 字幕（字体 msyh.ttc，底部安全区，y=h-th-60）。
- **片尾**：3–5s 静态品牌卡 + 淡入淡出（fade in/out 0.3s）。
- **三段 concat**：总时长 = 片头 6s + 正片 Ns + 片尾 3~5s。
- **BGM**：程序化轻垫（gen_xt_bgm 思路），音量压于人声之下，首尾淡入淡出；政策类稳重、赋能类明快。
