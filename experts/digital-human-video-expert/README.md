## 安装

将专家包目录放到专家目录下：

```
C:\Users\琼崖纵队\.workbuddy\plugins\marketplaces\my-experts\plugins/digital-human-video-expert/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```
