## 安装

将专家包目录放到以下路径：

```
~/.workbuddy/plugins/marketplaces/my-experts/plugins/bangshangyouming-helper/
```

然后运行注册命令使其在 WorkBuddy 中可见：

```bash
python3 scripts/register_expert.py ~/.workbuddy/plugins/marketplaces/my-experts/plugins/bangshangyouming-helper/
```

## 打包分享

```bash
zip -r bangshangyouming-helper.zip bangshangyouming-helper/
```
