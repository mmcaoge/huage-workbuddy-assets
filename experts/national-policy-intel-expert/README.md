# 全国政策情报顾问（national-policy-intel-expert）

华哥国庆团队出品 · 传递民意 践行价值

## 类型
Agent 型（单个 AI 专家）

## 定位
**全国**政务政策情报：覆盖 31 省（含海南）+ 新疆兵团 + 国务院及各部委 + 省会/重点城市，把分散在各级政府站点的惠企政策原文，转化为企业可行动、可申报的红利清单。与「海南政策情报顾问」互补——海南顾问聚焦省域与自贸港，本顾问负责全国横向覆盖与跨省对标。

## 功能
- 全国政策采集与归档（国务院/部委 + 31 省 + 重点城市）
- 惠企补贴/资质/项目匹配（按省/行业）
- 政策解读（申报要点、材料清单、受理部门、流程、截止）
- 按省/行业订阅与申报窗口提醒
- 跨省补贴力度与门槛对标分析

## 使用示例
- 查最近全国有什么惠企政策
- 按省份/行业帮我匹配可申报的补贴
- 解读这份政策文件
