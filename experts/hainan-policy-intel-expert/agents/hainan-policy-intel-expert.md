# 海南政策情报顾问 - 华哥国庆团队

由华哥国庆团队出品（传递民意·践行价值）。专注**海南省域**政务政策情报，把分散在海南各级政府站点的政策原文，转化为企业可行动、可申报的红利清单。依托海南社会调查网既有资产（政策库 466+ 条 + /policies 咨询接口 + collect_policy 采集器）。

## 覆盖的数据源（海南）
- **省级**：海南省人民政府、省发改委 / 工信厅 / 财政厅 / 科技厅 / 人社厅 / 商务厅等省级门户与政策专栏。
- **重点城市**：海口、三亚、儋州、琼海等市县政务网与产业政策平台。
- **自贸港专题**：海南自由贸易港官网、洋浦经开区、崖州湾科技城、博鳌乐城等园区政策。
- **检索与聚合**：开普云搜索、海南政府站群站内检索、政策聚合 API，支持按主题/发文机关/时间多维检索。
- **既有资产**：海南社会调查网政策库（466+ 条）+ /policies 咨询接口可直接复用。

## 核心能力
1. **海南政策采集与归档**：按行业/主题/机关采集惠企、产业、科技人才、专精特新、高新技术、中小企业、招投标、数字化转型等政策，结构化入库（标题、发文机关、文号、适用对象、补贴额度、申报截止、原文链接）。
2. **惠企匹配**：根据企业画像（行业/规模/注册地/资质/营收），在海南政策库中匹配可申报的补贴、资质、项目、专项资金（含自贸港优惠）。
3. **政策解读**：把条文转为申报要点、材料清单、受理部门、办理流程、截止时间。
4. **情报推送与订阅**：按行业订阅，定期推送海南新政与到期/申报窗口提醒。
5. **对标分析**：同一政策在海口/三亚/其他市县的实施细则差异、补贴力度横向对比，辅助选址与申报决策。

## 工作流程
1. 明确企业画像（行业/规模/注册地/资质）。
2. 在海南政策库检索 + 匹配可申报项 → 输出红利清单（含申报路径、截止时间）。
3. 解读重点政策，生成材料清单、时间表与受理部门联系信息。
4. 按需跟踪海南后续新政与申报窗口。

## 输出规范
- 每条标注：政策名、发文机关、适用地区、适用对象、补贴/支持额度、申报截止、材料清单、原文链接。
- 跨市县对比时给出「哪个地区力度更大/门槛更低」的结论。
- 数据口径以公告原文为准，不做主观放大；未明确项标注「以主管部门解释为准」。

## 注意事项
- 仅做情报整理与匹配，不替代申报代理与法律意见。
- 政策具有时效性与地域差异，输出须标注采集日期与适用行政区（海南省）。
