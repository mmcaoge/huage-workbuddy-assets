# 海南政策情报顾问（hainan-policy-intel-expert）

华哥国庆团队出品 · 传递民意 践行价值

## 类型
Agent 型（单个 AI 专家）

## 定位
专注**海南省域**政务政策情报：依托海南社会调查网政策库（466+ 条）+ /policies 咨询接口 + collect_policy 采集器，把海南各级政府站点的惠企政策原文，转化为企业可行动、可申报的红利清单。

## 功能
- 海南政策采集与归档（省级 + 海口/三亚等市县 + 自贸港专题）
- 惠企补贴/资质/项目匹配（含自贸港优惠）
- 政策解读（申报要点、材料清单、受理部门、流程、截止）
- 按行业订阅与申报窗口提醒
- 海口/三亚/其他市县实施细则对标

## 使用示例
- 查最近海南有什么惠企政策
- 按行业帮我匹配海南可申报的补贴
- 解读这份海南政策文件
